# Messages « commente un mot-clé » — à copier-coller

Quand quelqu'un commente le mot-clé sous un reel :
1. **Réponds sous son commentaire** (réponse publique) : ça montre aux autres que ça marche et ça relance le reel.
2. **Envoie le DM** avec le lien (copie le message du compte). Varie un peu la réponse publique d'une fois à l'autre.

Astuce : depuis l'app, appuie longuement sur le commentaire → « Envoyer un message » pour ouvrir directement la conversation.
Si les commentaires deviennent trop nombreux pour répondre à la main : passer à ManyChat (même mot-clé, même message).
